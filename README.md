# Sun Tzu Chess Scene (Unity)

Сцена `Assets/Scenes/SunTzuChess.unity` создаёт прототип поля 8x8 в стиле шахмат с акцентом на мотивы «Искусства войны»:

- процедурная генерация доски;
- символы «Генерал» и «Стратег» по сторонам поля;
- центральная метка «доктрина» как точка контроля пространства.

## Как запустить

1. Откройте проект в Unity (3D Core).
2. Загрузите сцену `Assets/Scenes/SunTzuChess.unity`.
3. Нажмите Play.

В консоль выводится формулировка цели уровня и тактической идеи.
