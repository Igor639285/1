# LAN Media Viewer

Простой проект для локального шаринга фото/видео с ПК на ТВ/телефон в одной Wi‑Fi сети.

## Структура

- `backend/` — Node.js + Express API
- `frontend/` — минимальный HTML/JS интерфейс
- `storage/` — временное хранение загруженных файлов

## Запуск на ПК

1. Установите Node.js 18+.
2. Установите зависимости:

   ```bash
   cd backend
   npm install
   ```

3. Запустите сервер:

   ```bash
   npm start
   ```

4. Откройте в браузере ПК:

   ```
   http://localhost:3000 (или следующий свободный порт)
   ```

## Важно для ТВ/телефона

ТВ/телефон и ПК должны быть в **одной Wi‑Fi/LAN сети**.

После загрузки файла UI покажет ссылку вида:

```text
http://<LAN_IP>:<PORT>/view/<id>?token=<secret>
```

Откройте её на ТВ/телефоне.

## Пример использования

1. Выберите фото/видео в интерфейсе.
2. Нажмите «Загрузить и получить ссылку».
3. Скопируйте ссылку.
4. Откройте ссылку на ТВ.

## API

- `POST /api/media` — загрузка файла (поле `media`, только `image/*` и `video/*`, лимит по размеру).
- `GET /api/share/:id?token=...` — выдача LAN-ссылки для просмотра.
- `GET /view/:id?token=...` — страница просмотра (`<video>` или `<img>`).
- `GET /media/:id?token=...` — безопасная раздача файла, поддержка `Range` для видео.

## Безопасность и срок жизни

- Ссылка использует токен (`id + secret token`).
- TTL по умолчанию: 24 часа.
- Просроченные файлы автоматически удаляются по расписанию.

Переменные окружения:

- `PORT` (базовый порт, по умолчанию `3000`; если занят, сервер попробует следующие порты)
- `SHARE_TTL_MS` (по умолчанию `86400000`)
- `MAX_FILE_SIZE_BYTES` (по умолчанию `524288000`)
- `CLEANUP_INTERVAL_MS` (по умолчанию `3600000`)
