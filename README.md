# Sun Tzu — Art of War (Unity prototype)

Обновлённый прототип с рабочими кнопками, 3rd-person управлением, боевым UI и командованием союзниками.

## Что сделано

### Главное меню (UI)
- Рабочие кнопки **Уровни / Настройки / Выход** через Unity UI (`Canvas + Button`).
- Автосборка интерфейса при загрузке сцены `MainMenu`.

### Выбор уровней (UI)
- 5 UI-кнопок уровней.
- Изначально доступен только 1-й уровень.
- После победы на уровне открывается следующий.

### Уровень 1: Ambush
- Камера от 3-го лица с поворотом мышью.
- Управление персонажем от 3-го лица (WASD + Shift).
- Более динамичный бой: обновлённые статы, интервалы атак, поведение ИИ для мили/дальних.
- Переключение на союзников: `Tab`.
- Команды союзникам:
  - `ПКМ` — перемещение в указанную точку
  - `T` — сфокусировать союзников на цели под курсором
- Атака контролируемым бойцом: `ЛКМ` (ближняя атака по ближайшему врагу в радиусе).
- Боевой HUD-подсказка через Unity UI.

## Ключевые скрипты
- `RuntimeUiBuilder` — строит UI меню/выбора уровней/HUD на Canvas.
- `ThirdPersonCameraController` — камера 3-го лица + мышь.
- `SquadCommandController` — переключение бойца и команды союзникам.
- `SunTzuSimpleMover` — движение контролируемого бойца.
- `Combatant`, `NpcAiController` — боевая логика и ИИ.
- `MissionController`, `GameProgress` — победа/поражение и прогресс уровней.

## Как запускать
1. Добавьте сцены в Build Settings:
   - `MainMenu`
   - `LevelSelect`
   - `Level1_Ambush`
2. Запустите с `MainMenu`.
